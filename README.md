
# RentReality Frontend

RentReality is a property management and search application developed using Angular.

This project is the frontend component of the RentReality full-stack application for COM661 Coursework 2.

## Technologies

- Angular (CLI version 22.2.5)
- TypeScript
- HTML
- CSS
- Flask REST API (backend)
- MongoDB (database)

## Installation

Clone the repository and open the project folder.

Install the required dependencies:

```bash
npm install
```

## Running the Application

Start the Angular development server:

```bash
ng serve
```

Open the application in your browser:

http://localhost:4200/

## Building the Application

Create a production build:

```bash
ng build
```

## Running Unit Tests

Run the Angular unit tests:

```bash
ng test
```

## Project Development

The frontend is being developed as part of COM661 Coursework 2.

The application will integrate with the existing RentReality Flask REST API to support property searching, property details, user authentication and property management.
